## 📌 프로젝트 개요

**7700**은 개인 칼로리 관리 및 다이어트 목표 달성을 위한 웹 애플리케이션입니다.
- 식사, 운동, 체중 기록
- AI 기반 칼로리 추정 및 피드백
- 일일/누적 칼로리 계산
- 통계 차트 및 진행 상황 추적

**개발 기간**: 2026-06-23 ~ 2026-07-11 (19일)
**웹 전환**: 2026-08-08

---

## 🛠️ 기술 스택

### 프론트엔드
- **Vite** (v8) + **React** 19.0 + **TypeScript** 5.6
- **TanStack Router** (코드 기반 라우팅)
- **Tailwind CSS** v4 + **shadcn/ui** (Radix 기반 컴포넌트)
- **Zustand** (상태 관리)
- **React Hook Form** + **Zod** (폼 검증)
- **Recharts** (차트)

### 백엔드
- **Supabase** (PostgreSQL, Auth, Edge Functions)
- **OpenAI API** (gpt-4o-mini)

### 개발 도구
- Git, npm, VS Code
- Jest (유닛 테스트 51개)

## 🗄️ 데이터베이스 스키마

### 9개 테이블

| 테이블 | 설명 |
|--------|------|
| `profiles` | 사용자 프로필 (키, 체중, 생년월일, 성별, 활동 수준) |
| `goals` | 목표 (목표 체중, 시작일, 목표일) |
| `meal_logs` | 식사 기록 (음식명, 칼로리, 매크로) |
| `exercise_logs` | 운동 기록 (운동명, 소모 칼로리, 시간) |
| `weight_logs` | 체중 기록 (체중, 측정 시간대) |
| `daily_summaries` | 일일 칼로리 집계 (섭취, 소모, 적자, 누적) |
| `llm_parse_logs` | AI 파싱 로그 |
| `llm_feedbacks` | AI 피드백 (일일/주간) |
| `health_workout_sync_logs` | HealthKit 동기화 로그 (웹 버전에서는 미사용) |

### 주요 테이블 구조

#### profiles
```sql
create table profiles (
  id uuid primary key,
  user_id uuid references auth.users(id),
  height_cm numeric(5,2) not null,
  current_weight_kg numeric(5,2) not null,
  birth_date date not null,
  gender text check (gender in ('male', 'female', 'other')),
  activity_level text check (activity_level in
    ('sedentary', 'light', 'moderate', 'active', 'very_active')
  ),
  created_at timestamptz default now()
);
```

#### meal_logs
```sql
create table meal_logs (
  id uuid primary key,
  user_id uuid references auth.users(id),
  meal_date date not null,
  meal_type text check (meal_type in
    ('breakfast', 'lunch', 'dinner', 'snack', 'late_night')
  ),
  food_name text not null,
  calories integer not null,
  protein_g numeric(6,2),
  carbs_g numeric(6,2),
  fat_g numeric(6,2),
  memo text,
  created_at timestamptz
);
```

#### daily_summaries
```sql
create table daily_summaries (
  id uuid primary key,
  user_id uuid references auth.users(id),
  summary_date date not null,
  total_intake_calories integer default 0,
  total_exercise_calories integer default 0,
  net_calories integer default 0,
  calorie_delta integer default 0,
  cumulative_delta integer default 0,
  estimated_weight_change_kg numeric(6,2),
  created_at timestamptz,
  unique(user_id, summary_date)
);
```

### RLS 정책

모든 테이블에 Row Level Security 적용:
- `auth.uid() = user_id` 조건으로 본인 데이터만 접근 가능
- SELECT, INSERT, UPDATE, DELETE 정책 설정

## 🧮 핵심 계산 로직

### BMR (기초 대사량)
```typescript
// Mifflin-St Jeor 공식
function calculateBMR(
  weight_kg: number,
  height_cm: number,
  age: number,
  gender: 'male' | 'female'
): number {
  if (gender === 'male') {
    return 10 * weight_kg + 6.25 * height_cm - 5 * age + 5
  } else {
    return 10 * weight_kg + 6.25 * height_cm - 5 * age - 161
  }
}
```

### TDEE (총 에너지 소비량)
```typescript
const activityMultiplier = {
  sedentary: 1.2,      // 거의 운동 안 함
  light: 1.375,        // 주 1-3일 가벼운 운동
  moderate: 1.55,      // 주 3-5일 보통 운동
  active: 1.725,       // 주 6-7일 강도 높은 운동
  very_active: 1.9     // 매일 매우 강도 높은 운동
}

const TDEE = BMR * activityMultiplier[activityLevel]
```

### 일일 칼로리 계산
```typescript
const netCalories = totalIntake - totalExercise
const calorieDelta = netCalories - TDEE
const cumulativeDelta = previousCumulative + calorieDelta
const estimatedWeightChange = cumulativeDelta / 7700  // 1kg = 7700kcal
```

## 🚀 시작하기

### 1. 환경 변수 설정

`.env` 파일 생성:
```bash
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 2. 의존성 설치

```bash
npm install
```

### 3. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 http://localhost:8081 접속

### 4. 테스트 실행

```bash
npm test        # Jest 51개
npm run typecheck
```

### 5. shadcn/ui 컴포넌트 추가

```bash
npx shadcn@latest add <component>
```

생성물은 `src/components/ui/` 에 복사되며 직접 수정해도 된다.
