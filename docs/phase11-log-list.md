# Phase 11 — 기록 목록 조회·수정·삭제

## 목표

기록 탭에서 날짜별로 저장된 식사·운동·체중 기록을 확인하고,  
수정 및 삭제할 수 있도록 한다.  
현재는 추가만 가능하고 기존 기록을 볼 수 없는 상태.

---

## 변경 파일

| 파일 | 작업 |
|------|------|
| `src/app/(tabs)/add-log.tsx` | 폼 아래에 날짜별 기록 목록 추가 |

스토어는 모두 기존 것 재사용 (`fetchLogs`, `updateLog`, `deleteLog` 이미 구현됨).

---

## UI 구성

```
기록 추가                    ← 기존 타이틀

[ 🍎 Apple Health 동기화 ]   ← 기존

날짜  [2026-06-26]           ← 기존 날짜 피커

[ 식사 | 운동 | 체중 ]        ← 기존 탭

(폼 입력 영역)               ← 기존

──────────────────────────
  오늘 기록                  ← 신규: 날짜에 해당하는 기록 목록
──────────────────────────
  🍽 비빔밥          550 kcal  [삭제]
  🍽 아메리카노       10 kcal  [삭제]
  🏃 러닝           300 kcal  [삭제]
  ⚖ 70.5 kg                   [삭제]
```

- 탭(식사/운동/체중)에 따라 해당 카테고리 기록만 표시
- 날짜 변경 시 목록 자동 갱신
- 기록 없으면 "이 날짜에 기록이 없습니다." 안내

---

## 수정 기능

행(Row)을 탭하면 수정 모달이 올라옴. 모달 내용은 해당 폼과 동일.

| 탭 | 수정 가능 필드 |
|----|---------------|
| 식사 | 식사 종류, 음식 이름, 칼로리, 단백질·탄수화물·지방, 메모 |
| 운동 | 운동 이름, 소모 칼로리, 운동 시간, 메모 |
| 체중 | 체중(kg), 측정 시간대, 메모 |

저장 시 `updateLog(id, data)` 호출 → `calculateAndSave(date)` 호출.

---

## 삭제 기능

[삭제] 버튼 탭 → 확인 Alert → `deleteLog(id)` 호출 → `calculateAndSave(date)` 호출.

```
Alert: "이 기록을 삭제하시겠습니까?"
  [취소]  [삭제 (빨강)]
```

---

## 데이터 로드 시점

- 날짜 변경 시 → 각 스토어 `fetchLogs(date)` 호출
- 탭 변경 시 → 해당 탭 스토어 `fetchLogs(date)` 호출  
- 저장 완료 후 → 자동 갱신 (기존 `fetchLogs` 가 addLog 내에서 호출됨)
