# 테스트 체크리스트

## Phase 10 — 설정 화면

### 설정 탭 진입
- [ ] 탭 바에 "설정" 탭이 표시되는지 (홈/기록/통계/설정 순서)
- [ ] 탭 진입 시 프로필·목표 데이터가 화면에 표시되는지
- [ ] 다른 탭에서 수정 후 설정 탭으로 돌아왔을 때 최신 데이터가 반영되는지

### 프로필 수정 모달
- [ ] "수정 →" 탭 시 모달이 올라오는지
- [ ] 모달 열릴 때 기존 값이 폼에 미리 채워져 있는지
- [ ] 키·체중 숫자 입력 및 유효성 오류 메시지 (범위 초과 등)
- [ ] 생년월일 날짜 피커 동작
- [ ] 성별 칩 선택
- [ ] 활동 수준 칩 선택
- [ ] "저장" 탭 후 설정 화면의 프로필 값이 업데이트되는지
- [ ] 체중을 변경했을 때 기록 탭 > 체중 항목에 오늘 날짜로 자동 추가되는지
- [ ] 체중을 변경했을 때 홈 화면의 유지 칼로리(TDEE)가 재계산되는지
- [ ] 체중을 변경하지 않으면 weight_logs에 중복 추가되지 않는지
- [ ] "취소" 탭 시 저장 없이 모달이 닫히는지

### 목표 수정 모달
- [ ] "수정 →" 탭 시 모달이 올라오는지
- [ ] 모달 열릴 때 기존 목표 체중·목표일이 미리 채워져 있는지
- [ ] 목표일로 오늘 이전 날짜 선택 시 오류 메시지
- [ ] "저장" 탭 후 설정 화면의 목표 값·남은 일수·일일 필요 적자가 업데이트되는지
- [ ] 목표 수정 후 홈 화면 목표 진행 카드에 반영되는지
- [ ] "취소" 탭 시 저장 없이 모달이 닫히는지

### 로그아웃
- [ ] "로그아웃" 탭 시 확인 Alert 표시
- [ ] Alert "취소" 탭 시 로그아웃되지 않는지
- [ ] Alert "로그아웃" 탭 시 로그인 화면으로 이동하는지
- [ ] 로그아웃 후 재로그인 시 데이터가 정상 복원되는지

## 전체 앱 회귀 테스트 (Phase 1–10 통합)

### 인증
- [ ] 회원가입 → 온보딩 → 홈 화면 이동
- [ ] 앱 재시작 후 로그인 상태 유지

### 홈 대시보드
- [ ] 식사·운동 기록 후 "오늘 칼로리" 즉시 반영
- [ ] 기록 탭에서 날짜 변경 후 홈 탭으로 돌아와도 오늘 데이터 유지
- [ ] 목표 진행률 퍼센트 계산 정확성

### 기록 탭
- [ ] 식사 저장 → 홈 칼로리 반영
- [ ] 운동 저장 → 홈 소모 칼로리 반영
- [ ] 체중 저장 → 통계 체중 그래프 반영
- [ ] Apple Health 동기화 버튼 (iOS) — 권한 요청 → 동기화 완료 Alert
- [ ] AI 칼로리 추정 버튼 — 음식명 입력 후 칼로리 자동 채워지는지 (OpenAI 크레딧 있을 때)

### 통계 탭
- [ ] 체중 그래프 데이터 표시 및 터치 툴팁
- [ ] 칼로리 바 그래프 색상 (적자=초록, 초과=빨강)
- [ ] 누적 적자 그래프 터치 툴팁
- [ ] 데이터 없을 때 빈 상태 메시지
