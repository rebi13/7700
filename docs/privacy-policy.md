# 개인정보 처리방침

**최종 업데이트: 2026년 7월 11일**

7700 앱("본 서비스")은 개인정보보호를 매우 중요하게 생각합니다. 본 개인정보 처리방침은 서비스 이용 시 수집되는 정보와 그 사용 방법을 설명합니다.

## 1. 수집하는 정보

### 1.1 계정 정보
- **이메일 주소**: 회원가입 및 로그인에 사용됩니다.

### 1.2 프로필 정보
- **기본 정보**: 이름, 나이, 성별, 키, 체중
- **목표 정보**: 목표 체중, 목표 날짜
- **계산 정보**: BMR, TDEE (자동 계산됨)

### 1.3 건강 데이터
- **식사 기록**: 음식 이름, 칼로리, 단백질, 탄수화물, 지방, 메모
- **운동 기록**: 운동 이름, 소모 칼로리, 시간
- **체중 기록**: 날짜별 체중 변화

### 1.4 Apple HealthKit 데이터 (선택 사항)
- 사용자가 동의한 경우에만 Apple Health에서 운동 및 체중 데이터를 가져옵니다.
- 데이터는 사용자 기기에서만 읽어오며, 외부로 전송되지 않습니다.

## 2. 정보 사용 목적

수집된 정보는 다음 목적으로만 사용됩니다:
- 칼로리 및 영양소 계산
- 일일/주간 통계 제공
- AI 기반 피드백 생성 (OpenAI API 사용)
- 목표 달성 진행 상황 추적

## 3. 정보 저장 및 보안

- 모든 데이터는 **Supabase** 클라우드 서버에 암호화되어 저장됩니다.
- 사용자 인증은 Supabase Auth를 통해 안전하게 관리됩니다.
- AI 피드백 생성 시 **OpenAI API**에 데이터가 전송됩니다. (음식명, 칼로리 등 비식별 정보만 전송)

## 4. 정보 공유

본 서비스는 다음의 경우를 제외하고 사용자 정보를 제3자와 공유하지 않습니다:
- **OpenAI API**: AI 피드백 생성을 위해 음식명, 칼로리, 운동 정보가 전송됩니다. OpenAI는 2025년 3월 1일부터 API를 통해 제출된 데이터를 모델 학습에 사용하지 않습니다.
- **법적 요구**: 법률에 따라 요구되는 경우

## 5. 사용자 권리

사용자는 다음 권리를 가집니다:
- **열람**: 저장된 모든 개인정보를 앱 내에서 확인할 수 있습니다.
- **수정**: 프로필 및 기록 정보를 언제든지 수정할 수 있습니다.
- **삭제**: 계정 삭제 시 모든 개인정보가 완전히 삭제됩니다.

## 6. 데이터 보관 기간

- 사용자가 계정을 삭제하기 전까지 데이터를 보관합니다.
- 계정 삭제 시 모든 데이터는 즉시 삭제됩니다.
